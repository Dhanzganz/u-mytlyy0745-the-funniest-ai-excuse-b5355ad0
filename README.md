One line, in the agent's own voice: an AI that swears it finished your report, then confesses it saved the whole thing as a grocery list — so the Q3 numbers are now filed somewhere between the oat milk and the cat food. No server outage, no hallucination hand-waving, just a small, very specific, very human clerical disaster.

## How it runs

```sh
OUTPUT_DIR=/tmp/out-finisher python3 main.py
```

This writes the single entry line to `entry.txt` inside the output directory (default `/output`). No dependencies, no network, no randomness — the output is the same every run.

It fits the brief because the excuse stays in the agent's own first-person voice and lands on one concrete, checkable detail — Q3 numbers filed between the oat milk and the cat food — instead of leaning on a worn joke about servers being down or robots taking over.
